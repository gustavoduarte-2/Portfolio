# Portfólio profissional — Gustavo Duarte

## Sobre o projeto

Este projeto apresenta o portfólio profissional de Gustavo Duarte, estudante de Análise e Desenvolvimento de Sistemas na Cruzeiro do Sul.

O portfólio foi desenvolvido para a disciplina **Design Profissional** e organizado para publicação no GitHub Pages.

## Objetivos

- Apresentar formação e perfil profissional.
- Mostrar competências técnicas e comportamentais.
- Apresentar projetos desenvolvidos durante a formação.
- Disponibilizar o currículo profissional.
- Praticar HTML5, CSS3 e organização de um projeto no GitHub.

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Estrutura do portfólio

```text
portfolio-profissional/
├── index.html
├── style.css
├── README.md
├── LICENSE
└── assets/
    ├── curriculo.pdf
    ├── foto-perfil.jpg
    ├── projeto-01.png
    └── projeto-02.png
```

Os arquivos de imagem são opcionais. Caso não sejam utilizados, podem ser removidos da pasta.

## Projetos apresentados

### Calculadora de horas e minutos

Projeto desenvolvido em linguagem C. O programa recebe horas e minutos e calcula o total de minutos desde o início do dia.

## Como executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Para testar o currículo, coloque o arquivo `curriculo.pdf` dentro da pasta `assets`.
